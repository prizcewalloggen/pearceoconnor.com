Storyblok Demo Page

🚀 Storyblok Integration Ready!

To see content here, you need to:

  1. Create a Storyblok account at storyblok.com
  2. Get your Preview Access Token from Settings → Access Tokens
  3. Copy .env.example to .env and add your token
  4. Create a story called "storyblok-demo" in your Storyblok space
  5. Add components like Page, Feature, Grid, or Teaser
  6. Restart the dev server to see your content!

Available Components:

  • Page - Full page layout with title and body
  • Feature - Feature card with icon, name, and description
  • Grid - Responsive grid container for other components
  • Teaser - Content teaser with image, headline, text, and link
